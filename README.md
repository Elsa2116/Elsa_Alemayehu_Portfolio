# Elsa Alemayehu Portfolio

Responsive React + Vite + Tailwind + Framer Motion portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Node version

Use Node 24 LTS.

The repo includes:

```txt
.nvmrc
.node-version
netlify.toml
package.json engines
```

## Deploy

Build command:

```bash
npm run build
```

Output / publish directory:

```txt
dist
```
